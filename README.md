# Антибот: поиск ботов по событиям cookie

| версия | что внутри | P@R, forward-CV | P@R, leave-2-days-out | PR-AUC |
|---|---|---|---|---|
| baseline из quickstart | RandomForest на 2 признаках | 0.096 | 0.097 | 0.213 |
| v1 | 77 поведенческих признаков, 2 LightGBM | 0.765 | 0.787 | 0.796 |
| v2 | + курсор, сессии, модель на уровне событий, ансамбль из 5 моделей | 0.775 | 0.829 | 0.810 |
| v3 | + связи кук через общие объявления, ансамбль перенастроен | 0.868 | 0.879 | 0.833 |

v3 лучше v2 на 0.093 по forward-CV и на 0.050 по leave-2-days-out, вероятность улучшения по бутстрапу 1.0.
При recall 0.7 v3 ошибочно отмечает около 87 людей против 130 у v2.

v2 и v3 посчитаны в одном цикле CV финального ноутбука с 3 сидами. На платформе v3 получила P@R 0.8997.

## Файлы

- `solution.ipynb` - решение (v3): EDA, признаки, связи через объявления, валидация, модели, сабмит, проверенные идеи, выводы.
- `submission.csv` - ответ для `data/test.csv`.
- `requirements.txt` - зависимости, Python 3.11.
- `metric.py` - официальная метрика.
- `experiments/` - код и логи проверок v1 и v2. Проверки v3 описаны в разделе 11 `solution.ipynb`.
- `v1/`, `v2/` - прошлые версии (ноутбуки в том же оформлении, с EDA) и их сабмиты. Их тоже нужно запускать
  из корня проекта: пути к `data/` и `metric.py` относительные.

## Запуск

1. Положите в `data/` файлы `train.csv`, `test.csv` и `events.csv.gz` из `bot_detection_challenge.zip`
   (данные в репозиторий не входят).
2. `pip install -r requirements.txt`
3. Запустите `solution.ipynb` целиком. Около 35 минут на 2 ядрах, с `RUN_CV = False` около 5 минут.

Сиды зафиксированы.

## Подход

1. Очистка: только события внутри окна (после окна лежат все `captcha_shown`, это утечка), сортировка по времени,
   удаление дублей, нормализация `platform` и `user_agent`.
2. Признаки куки: тайминг, состав событий, контент, пагинация, курсор и его траектория, сессии, клиент, возраст куки.
3. Модель на уровне событий: оценивает каждое событие с его окружением, оценки агрегируются по куке. Строится внутри
   фолдов, без утечки.
4. Связи кук через общие объявления (v3):
   - без меток: популярность объявлений куки среди других кук и поведение кук-соседей; только куки с окнами
     в тот же или более ранние дни;
   - с метками: пересечения с известными ботами; строятся внутри фолда только по меткам обучающей части
     и только за дни строго раньше окна куки, для обучающих строк - с задержкой меток 0-5 дней.
   Отсутствие утечки проверяется тремя `assert` в ноутбуке.
5. Ансамбль: три LightGBM, XGBoost и CatBoost с равными весами, каждая модель по 5 сидам. В v3 снижены
   learning rate, глубина и доля признаков на дерево, чтобы модели не держались на признаках связей.
6. Валидация по дням в двух схемах и парный бутстрап.

Библиотеки: pandas, numpy, scipy, scikit-learn, LightGBM, XGBoost, CatBoost, matplotlib. Для `experiments/` ещё
cleanlab, Optuna и PyTorch. Всё open-source, внешние API не используются.
