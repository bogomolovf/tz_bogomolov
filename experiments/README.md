# Эксперименты

Здесь проверялись идеи, прежде чем попасть или не попасть в решение. Итоговая таблица с цифрами -
в разделе 10 `v2/solution_v2.ipynb`, полный журнал - `experiments_log.csv`, вывод каждого скрипта - в `logs/`.

## Общий код

| файл | что делает |
|---|---|
| `base.py` | загрузка, очистка и признаки v1, взятые из ноутбука |
| `harness.py` | ранний стенд: кэш признаков, forward-CV, бутстрап |
| `lab.py` | основной стенд: две схемы валидации, бутстрап, запись в журнал |
| `feats_new.py` | новые признаки: курсор, сессии, n-граммы, User-Agent |
| `mil.py` | модель на уровне событий и агрегаты её оценок |

## Запуск

Запускать из этой папки, уровнем выше должны лежать `data/` и `metric.py`.
Сначала `python -c "import harness"` (строит кэш признаков), затем скрипты по порядку номеров:
`e03` сохраняет признаки для `e04`-`e06`, `e05` - таблицу событий, `e07` - кэш для `e08` и дальше.
Всё вместе занимает около 3.5 часов на 2 ядрах.

## Правило

Идея принимается, если улучшает обе схемы валидации и по парному бутстрапу лучше с вероятностью не ниже 0.9.
Та же модель с другими сидами меняет метрику на 0.007 - это уровень шума.
